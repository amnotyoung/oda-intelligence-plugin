# Privacy notice

The ODA Intelligence plugin package does not contain analytics code, user
accounts, client credentials, or a local data store.

When the plugin uses an MCP tool, the selected tool name and arguments are sent
to the public ODA Intelligence gateway. The service and its hosting provider
necessarily receive network and request metadata needed to operate, secure,
rate-limit, and troubleshoot the service. Tool requests may also be sent to the
public data source needed to answer them.

Do not put personal, confidential, classified, or credential material in tool
arguments. The public gateway is designed for open development-cooperation
research and may reject content that resembles personal contact information,
credentials, private URLs, or signed URLs.

The plugin does not change the license, privacy terms, or reuse conditions of
data returned by an upstream source. Follow the original source URL and the
source operator's terms before redistributing data or documents.

Report a privacy or security concern through GitHub private vulnerability
reporting for this repository, without including sensitive material in a public
issue.
