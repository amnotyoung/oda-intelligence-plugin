# Report standard

Use this default order unless the user requests another structure:

1. Executive summary
2. Standard country profile
3. Political, economic, humanitarian, and operating environment
4. International development-finance and aid landscape
5. Korean ODA portfolio and geographic coverage
6. Priority sectors and delivery or participation routes
7. Risk-specific Go, No-Go, and suspension conditions
8. Evidence limitations and interpretation cautions
9. Sources

Keep facts, interpretation, and recommendations visibly distinct. Put the observation year or reference date next to every quantitative claim.

Do not issue one unconditional report-wide Go or No-Go decision. Scope conditions to a risk, location, delivery route, partner type, or project component.

Use a chart, map, or diagram only when it materially clarifies a distribution, trend, geography, concentration, or sequence. Always include source, unit, observation period, coverage, and a text or table fallback.
